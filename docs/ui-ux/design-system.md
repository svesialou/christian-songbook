# UI/UX Design System (web-ориентированный)

## Направление
- Простота и удобство чтения на сцене/под сценой.
- Консервативная музыкальная типографика с акцентом на строковую длину.
- Не перегруженный интерфейс, «чистый» текстовый фокус.

## Typo и цвета
- Базовый размер body: 16px.
- Шрифт (рекомендация): Inter + fallback serif для печатного текста (можно корректировать на этапе реализации).
- Текстовая длина в строке: 35–70 символов на больших экранах.
- Ключевые токены: primary, secondary, warning, background, onBackground.

## Разметка и размеры
- Mobile-first.
- Спэйсинг кратен 4/8 px.
- Минимальные площади касания кнопок: 44×44dp.
- Нет hover-only поведения.

## Поведение
- Точка входа в «режим чтения» — без лишних навигационных элементов.
- Анимации: 150–300ms, не более 2 ключевых анимаций на экран.
- Плавные skeleton/loader'ы, без блокирующих спиннеров > 300ms.

## Важные запреты
- Нет emoji-иконок как UI-элементов.
- Нет нечитабельных цветовых контрастов.
- Не ломать масштабирование/переключение шрифта для людей с плохим зрением.
